# Aspiring Founders Meetup

The website for **Aspiring Founders Meetup (AFM)**, a Berlin community for people exploring entrepreneurship, building their first company, or becoming solopreneurs.

The site introduces the membership, founder events, expert helpdesks, partner offers, and waitlist.

## Tech stack

- Next.js 16
- React 19
- Tailwind CSS 4
- TypeScript

## Run locally

Requires Node.js 22.13 or later.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production build

```bash
npm run build
npm start
```

## Deploy to Vercel

Import this repository into Vercel. It is a standard Next.js application, so no custom configuration is required.

- Framework Preset: `Next.js`
- Build Command: `npm run build`
- Output Directory: leave blank
- Root Directory: repository root

## Project structure

```text
app/
  page.tsx       Main landing page
  layout.tsx     Site metadata and document layout
  globals.css    Global styling and responsive layout
public/assets/   Logos, partner imagery, and deal assets
```
